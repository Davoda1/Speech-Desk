# Changelog

## 1.1.0

- Add optional per-profile encrypted API-key storage with passphrase unlocking, explicit locking and replacement of an inaccessible credential.
- Add OpenAI Realtime speech generation and dated retirement handling for the older OpenAI Speech API models, preserving compatible self-hosted services.
- Center the microphone level meter in the bottom status row, expanding symmetrically from the middle.
- Replace the Live text checkbox with a matching checkable button and clarify progress as reading parts.
- Update the application guide, online manual, release documentation and dependency notices.

## 1.0.0

Initial release: native desktop text-to-speech with OpenAI, ElevenLabs, OpenRouter and self-hosted speech profiles; local Whistle/Whisper dictation; playback highlighting and WAV export; separate optional recognition-model ZIP packs.

See [release notes](docs/Release-Notes.md) for functionality and compatibility details.
